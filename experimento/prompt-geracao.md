# Prompt padrão de geração (fase F6)

O texto abaixo é **idêntico para os dois grupos** do experimento. A única coisa que muda é o documento colado depois dele (variável independente). Não altere o texto durante o experimento.

Use `python montar_prompts.py` para gerar os arquivos prontos para colar (`prompts/prompt-A-precisa.txt` e `prompts/prompt-B-livre.txt`), garantindo que o prompt e o documento sejam enviados exatamente iguais em todas as execuções.

```text
Implemente o software descrito no documento abaixo.
Responda somente com um único bloco de código Python contendo o arquivo completo biblioteca.py.

===== DOCUMENTO =====
```
